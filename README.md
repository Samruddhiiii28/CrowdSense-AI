# CrowdSense AI

## Predictive Crowd Intelligence & Safety System

CrowdSense AI is an AI-powered crowd monitoring and predictive
safety system designed to analyze crowd behavior from video streams.

## Main Technologies

- Python
- OpenCV
- YOLO11
- ByteTrack
- XGBoost
- LSTM
- FastAPI
- React
- MongoDB
- Docker

## Main Features

- Person detection
- Person tracking
- Crowd counting
- Crowd density estimation
- Multi-zone monitoring
- Crowd flow analysis
- Heatmap generation
- Risk prediction
- Crowd forecasting
- Safety alerts
- Decision support
- Real-time dashboard
